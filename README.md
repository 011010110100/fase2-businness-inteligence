# Fase 2 - Business Intelligence e Analytics

Projeto desenvolvido para análise de **cancelamentos de reservas hoteleiras** utilizando Business Intelligence e Analytics.

## Objetivo

Analisar características associadas aos cancelamentos de reservas e desenvolver um modelo preditivo para classificação de cancelamentos.

## Tecnologias

* Python
* Google Colab
* Pandas
* Scikit-learn
* Power BI

## Etapas

* Preparação e limpeza dos dados
* Criação de KPIs
* Análise descritiva e diagnóstica
* Análise das hipóteses
* Modelo preditivo com Regressão Logística
* Dashboard no Power BI

## Principais resultados

* Reservas com maior antecedência apresentaram maior taxa de cancelamento.
* Hóspedes recorrentes apresentaram menor taxa de cancelamento.
* O modelo preditivo apresentou **79,62% de acurácia** e **84,98% de precisão**.

## Arquivos

* `Fase2_BI_Hotel_Bookings.ipynb` — preparação, análise e modelo preditivo.
* `hotel_bookings.csv` — conjunto de dados utilizado no projeto.
